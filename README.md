# Sámara Viva — Revista digital

Revista digital independiente de carácter educativo sobre biodiversidad, conservación marina, recursos naturales, problemáticas ambientales, turismo responsable y actividades de Sámara Adventures.

## Uso

Abrir `index.html` en un navegador. Para publicar, colocar el archivo en la raíz del repositorio y activar **Settings > Pages > Deploy from a branch > main > /(root)**.

## Fotografías y marca

Este proyecto utiliza enlaces directos a fotografías y al logotipo disponibles públicamente en el sitio `https://samaraadventures.com/` y acredita su procedencia. No se han generado imágenes artificiales. Las fotografías se cargan desde el servidor de origen, por lo que podrían dejar de mostrarse si este cambia las rutas o restringe la inserción externa. Solicitar autorización a Sámara Adventures para el uso oficial de su logotipo y fotografías. La edición es independiente y no está avalada por la empresa.

## Identidad gráfica

El diseño utiliza naranja `#ff6900`, negro `#161616` y blanco `#ffffff`, aproximados a la identidad visual observable de la web y el logo. Sin acceso al archivo de estilos original no se garantiza coincidencia hexadecimal exacta con todos los tokens de diseño del sitio.
